# glyphh-releases

Public release artifacts for the **Glyphh** desktop app — signed macOS
(`.dmg` / `.zip`) and Windows (`.exe`) builds plus the `latest*.yml`
auto-update feeds. Published automatically by the
[`glyphh-ai/glyphh`](https://github.com/glyphh-ai/glyphh) build workflow on
each `v*` tag.

Grab the newest build from the **[Releases](../../releases)** page.

---

> _Glyphh was formerly **.yo**. This project was rebranded from .yo to Glyphh —
> older releases may still carry the `.yo` / `Yo` name._
